# 企业知识中心使用手册

本文说明员工、管理员与智能体如何使用企业知识中心。安装、配置与升级见 [部署手册](部署手册.md)。

## 1. 产品是什么

企业知识中心不是传统 Wiki，也不是以问答 / RAG 为中心的产品。它把制度、规范、经验沉淀为**可治理的企业知识资产**：先管空间、权限、版本、发布与审计，再同时开放给两类使用者。

| 使用者 | 入口 | 能做什么 |
| --- | --- | --- |
| 员工 | Web（浏览器） | 阅读、编辑、检索、管理空间与版本 |
| 智能体 / AI 工具 | Agent API、MCP | 在权限范围内只读已发布知识 |

两边读的是同一份内容、同一套权限。草稿和归档只给员工看，不对智能体开放。智能体不能写知识、不能管用户。

## 2. 登录与账号

1. 打开站点（开发环境一般为 http://localhost:3000 ；Docker 全栈一般为 http://localhost ）。
2. 使用用户名与密码登录。
3. 若管理员未关闭公开注册，可在登录页注册；注册账号固定为普通用户（`viewer`），不能自行指定管理员。
4. 新密码至少 8 位。登录失败次数过多会暂时锁定，请稍后再试。
5. 管理员修改你的密码后，原登录状态立即失效，需要用新密码重新登录。

首次部署由实施人员用 `init_admin.py` 创建管理员，不要依赖公开注册产生管理员。

侧栏底部显示当前用户名与系统角色。点击退出图标可登出。

## 3. 角色与权限

系统角色与空间角色是分开的。

### 3.1 系统角色

| 角色 | 典型能力 |
| --- | --- |
| owner / admin | 用户管理、系统配置、模块启停、查看审计、管理全部空间 |
| editor | 在有权限的空间内创建与编辑知识、上传附件、维护版本 |
| viewer | 浏览授权范围内的知识、检索、下载附件 |

公开注册得到的是 `viewer`。只有管理员能在「用户管理」中创建用户或调整系统角色。

### 3.2 空间可见性

创建空间时可选择：

| 可见性 | 含义 |
| --- | --- |
| 内部（internal） | 企业登录用户默认可读 |
| 私有（private） | 仅空间成员可访问 |
| 公开（public） | 全员可见并可检索 |

空间内还可把成员设为 owner、admin、editor、viewer，控制谁能改空间、谁能写知识。

### 3.3 发布状态

| 状态 | 员工 | 智能体 |
| --- | --- | --- |
| 草稿（draft） | 按权限可见、可继续编辑 | 不可见 |
| 已发布（published） | 可见 | 可检索、可读最新已发布版本 |
| 归档（archived） | 仍可在 Web 查看 | 不可见 |

写给 AI 用的内容必须先**发布**。

## 4. 界面导览

登录后主界面分为：

- **左侧目录**：知识空间与下属专题，可展开、刷新。
- **顶栏**：当前页面名称、全局搜索、配置中心（管理员）或 Agent 凭证（普通用户）。
- **主区**：空间列表、空间详情、知识阅读/编辑、检索结果等。

默认进入「空间概览」（`/spaces`）。

## 5. 空间与专题

### 5.1 空间

在空间概览创建空间：填写名称、说明、可见性。进入某个空间后可以：

- 查看该空间下的知识列表
- 新建知识
- 管理专题
- 管理空间成员（需相应空间权限）

删除空间属于高权限操作，删除前确认空间内知识是否仍需要。

### 5.2 专题

专题用于在空间内整理脉络（例如「出差报销」「值班制度」）。可在空间详情中创建专题，并在左侧目录中点选，过滤该专题下的知识。

## 6. 知识的创建、阅读与编辑

### 6.1 新建

在空间内新建知识，填写标题、正文、摘要、专题、标签等。保存时可选：

- **保存草稿**：只给有权限的员工看，智能体不可见。
- **发布**：生成正式版本，智能体可在权限范围内引用。

支持从 Markdown / HTML 文件导入，系统会尝试提取标题与摘要。导入后仍建议人工核对并明确发布状态。

### 6.2 阅读

知识详情页展示正文、状态、标签、附件与版本信息。仅当状态为「已发布」时，智能体才能取到该条知识的最新正式版本。

### 6.3 编辑与版本

编辑已有知识会生成新版本，可填写变更说明。可以：

- 查看历史版本
- 对比两个版本的差异
- 将某一历史版本恢复为当前内容（恢复后仍需按发布规则决定智能体是否可见）

不要把未审核的生成内容直接当权威来源发布。知识中心保存的是治理后的正文，而不是聊天记录。

## 7. 附件

在知识详情中上传、下载或删除附件。

- 允许的扩展名由管理员在存储配置中维护（如 `.md`、`.pdf`、`.png`）。
- 可执行类型（如 `.exe`、`.js`）会被拒绝。
- HTML 等可能在浏览器中执行的类型仍可按白名单上传，但下载时会作为附件强制下载，而不会当网页打开。
- 同名文件不会互相覆盖，系统使用独立存储名。

超过管理员设定的大小上限会被拒绝。

## 8. 检索

顶栏搜索进入全局检索。可按关键词在标题、摘要、正文中查找**已发布**且当前账号可见的知识，并可结合空间、专题、标签过滤。

生产环境 MySQL 使用全文索引；关闭搜索模块后，检索接口会返回空结果，但浏览与编辑不受影响。

## 9. 标签

标签用于跨空间标记主题。可在标签页维护标签，并在编辑知识时绑定。检索时可按标签缩小范围。

## 10. 管理员功能

管理员（及 owner）在顶栏进入 **配置中心**（`/settings`）。普通用户进入同一路由时，主要看到 Agent 凭证页。

### 10.1 数据大盘

查看知识数量、版本数、空间数、附件占用、用户数与审计条数等概况。

### 10.2 存储配置

可调整：

- 单文件上传大小（MB）
- 允许的扩展名

存储路径由服务器环境变量决定，界面只读。保存后立即作用于后续上传。

### 10.3 用户管理

- 查看用户列表（仅管理员）
- 添加用户（指定系统角色与初始密码）
- 启用 / 禁用账号

禁用后该用户无法继续调用需登录的接口。

独立页面 `/admin/users` 提供同类用户管理能力。

### 10.4 模块

可启用或停用搜索、文件导入等模块。核心浏览与权限不依赖大模型模块。

### 10.5 审计

审计记录登录、知识变更、空间与成员、附件以及 Agent 取用。人和智能体在日志中可区分，便于追溯「谁在什么范围读了哪条知识」。

## 11. 给智能体签发凭证

任意登录用户都可以在 **设置 → Agent 凭证** 为自己的智能体签发 Key。管理员能看到全部配置页，但不要把员工登录密码配进 Cursor、Claude 或其他 Agent。

### 11.1 签发

点击「签发 Agent」，填写：

| 项 | 说明 |
| --- | --- |
| 名称 | 例如「客服机器人」 |
| 用途说明 | 这个智能体做什么、由谁使用 |
| 可访问知识空间 | 多选；不选则沿用你本人可见的空间，且不能超出你的可见范围 |
| 只读能力 | 列出空间与专题、检索、读正文与引用、关联知识、版本列表、附件元数据 |

签发成功后，明文 Key **只显示一次**，请立即复制到安全的密钥保管处。之后只能撤销或改配置，不能再查看明文。

Key 形态类似 `kck_` 开头的一串字符。它只能调用 `/api/v1/agent/*`，不能创建/修改知识，不能管理用户。

### 11.2 后续配置

对仍有效的 Key 可点「配置」修改名称、说明、空间范围与只读能力，不必换 Key。不再使用时点「撤销」。

### 11.3 调用示例

HTTP 头：

```http
Authorization: Bearer kck_你的密钥
```

常用只读接口（均在 `/api/v1` 下）：

| 方法 | 路径 | 需要的能力 | 说明 |
| --- | --- | --- | --- |
| GET | `/agent/spaces` | list_spaces | 列出可见空间 |
| GET | `/agent/spaces/{id}/topics` | list_spaces | 列出专题 |
| GET | `/agent/search?q=出差报销` | search | 检索已发布知识 |
| POST | `/agent/search` | search | 带空间/类型等条件检索 |
| GET | `/agent/knowledge/{id}` | read | 读知识 |
| GET | `/agent/knowledge/{id}/latest` | read | 读已发布最新版本 |
| GET | `/agent/knowledge/{id}/versions` | versions | 版本列表 |
| GET | `/agent/related/{id}` | related | 关联知识 |
| GET | `/agent/knowledge/{id}/attachments` | attachments | 附件元数据 |

返回的已发布内容带引用，例如 `citation_uri` 为 `knowledge://12`。智能体对外回答时应带上该引用，而不是把知识中心当成可以随意改写的记忆库。

未授权的能力返回 403。草稿、归档、无权限空间中的知识不会出现在结果里。

### 11.4 MCP

在已安装后端依赖的前提下，用同一套 Key 启动 MCP（stdio）：

```powershell
$env:MCP_API_KEY = "kck_..."
Set-Location apps/server
python -m app.mcp_server
```

也可设置 `MCP_AUTH_USER` 作为次选身份。两者都缺时不会回落到管理员账号。MCP 与 Web、Agent REST 遵守同一数据与权限。

## 12. 使用原则（给人和 AI）

1. **先治理再开放**：空间、成员、发布状态不清楚时，不要把内容交给智能体。
2. **一份知识两种入口**：员工在 Web 看到的已发布正文，应与 Agent 在权限内取到的一致。
3. **AI 是消费者**：模型可以检索和引用，不能把未审核的生成结果写成权威知识。
4. **关闭大模型系统仍可用**：检索、权限、版本、审计不依赖外部 LLM。
5. **最小权限**：给智能体只勾选需要的只读能力，并尽量限制空间范围。

## 13. 常见问题

**为什么智能体搜不到刚写的文章？**

确认已点击发布，且签发 Key 时勾选了检索/读取能力，并且该知识所在空间在 Key 的空间范围内。

**普通用户看不到用户列表或存储配置？**

这些能力仅管理员可用。普通用户在设置里主要管理自己的 Agent 凭证。

**上传失败？**

检查文件扩展名是否在白名单中、是否超过大小限制，以及是否对当前知识有编辑权限。

**页面一直跳回登录？**

登录已过期、管理员刚改过密码，或后端未启动。请重新登录；若刚部署，先确认服务可用（见 [部署手册](部署手册.md)）。
